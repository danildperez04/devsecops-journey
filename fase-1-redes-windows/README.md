# Fase 1 — Redes, internet y Windows

**Duración:** 9–11 semanas

**Meta:** Entender qué pasa entre una URL y la página, y cómo funciona una red Windows con Active Directory.

## Temas

- [ ] OSI y TCP/IP, IP, subredes, CIDR
- [ ] TCP/UDP, DNS, DHCP, NAT
- [ ] HTTP/HTTPS y TLS
- [ ] ping, curl, dig, ss, nmap, Wireshark
- [ ] Windows por dentro y PowerShell
- [ ] Active Directory, NTLM y Kerberos, SMB/RDP/WinRM

Captura con Wireshark de una página web documentada + dominio AD pequeño en tu laboratorio.
