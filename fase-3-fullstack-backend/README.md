# Fase 3 — Fullstack II: backend, bases de datos y móvil

**Duración:** 16–18 semanas

**Meta:** Cerrar el ciclo fullstack: APIs con base de datos, autenticación y pruebas, conectadas al frontend y a una app móvil.

## Temas

- [ ] Node.js y Express
- [ ] PostgreSQL, modelado, ORMs
- [ ] NestJS
- [ ] Autenticación (JWT, refresh) y RBAC
- [ ] Pruebas con Jest, OpenAPI
- [ ] Redis, colas, WebSockets
- [ ] PHP + MariaDB con PDO
- [ ] Expo/React Native (opcional)
- [ ] Despliegue en tu Debian
- [ ] Seguridad en todo el stack

## Proyecto

API NestJS + PostgreSQL con frontend, app móvil opcional y despliegue en tu servidor. La atacarás en la Fase 6.
